TurboWarp custom extension

Wait for the signal you need.

Coordinate scripts with named notifications, keyboard events, and optional timeouts—without polling.

controllersend “next”→waiting scripts

01 · Install

Use the reviewed 0.1.1 build.

  1. Open TurboWarp Desktop.
  2. Add the version-pinned URL below as a custom extension.
  3. Enable Run extension without sandbox when prompted.
https://cdn.jsdelivr.net/npm/@kubohiroya/turbowarp-extended-notification@0.1.1/dist/extended-notification.js

Why unsandboxed? Keyboard waits listen for browser key events and all waits are cancelled when the TurboWarp runtime stops. Load the extension only from a source you trust.

For a local dependency, run:

npm install --save-exact @kubohiroya/turbowarp-extended-notification@0.1.1

02 · Blocks

Send, wait, or race a timeout.

Send a notification

send extended notification [MESSAGE]

Resumes every script already waiting for the same name.

Wait for a notification

wait until extended notification [MESSAGE] is received

Pauses this script until that notification arrives.

Wait with a timeout

extended notification [MESSAGE] received before [SECONDS] seconds

Returns true for the notification and false for timeout or project stop.

Wait for a key

wait until [KEY] key is pressed

Observes a new keydown after the block starts waiting.

Wait for a key or timeout

[KEY] key pressed before [SECONDS] seconds

Returns which event happened first.

03 · Behavior

Notifications are live signals, not a queue.

  • A send resumes all current waiters with the same name.
  • A notification sent before a wait begins is not retained.
  • Register the waits before the controller sends its signal.
  • Repeated keydown events from holding a key are ignored.
  • Zero, negative, and non-finite timeouts expire immediately.
  • Starting or stopping the project cancels pending waits.

See the complete behavior specification for normalization and compatibility details.
