TurboWarpカスタム拡張機能

必要な合図を待つ。

名前付き通知、キーボードイベント、任意のタイムアウトを使い、 ポーリングせずにスクリプト同士を連携できます。

コントローラー「next」を通知→待機中のスクリプト

01 · 導入

レビュー済みの0.1.1を使う。

  1. TurboWarp Desktopを開きます。
  2. 次のバージョン固定URLをカスタム拡張機能として追加します。
  3. 確認画面でサンドボックスなしで実行を有効にします。
https://cdn.jsdelivr.net/npm/@kubohiroya/turbowarp-extended-notification@0.1.1/dist/extended-notification.js

なぜサンドボックスなしで実行するのですか？ キー入力の待機ではブラウザーのキーイベントを監視し、TurboWarpランタイムの停止時には すべての待機を解除するためです。信頼できる配布元からだけ読み込んでください。

ローカルの依存関係として導入する場合:

npm install --save-exact @kubohiroya/turbowarp-extended-notification@0.1.1

02 · ブロック

通知する、待つ、タイムアウトと競争する。

通知を送る

send extended notification [MESSAGE]

同じ名前の通知をすでに待っているすべてのスクリプトを再開します。

通知を待つ

wait until extended notification [MESSAGE] is received

その名前の通知が届くまで、このスクリプトを一時停止します。

タイムアウト付きで待つ

extended notification [MESSAGE] received before [SECONDS] seconds

通知ならtrue、タイムアウトまたはプロジェクト停止ならfalseを返します。

キーを待つ

wait until [KEY] key is pressed

ブロックが待機を始めた後の新しいkeydownを監視します。

キーまたはタイムアウトを待つ

[KEY] key pressed before [SECONDS] seconds

どちらのイベントが先に起きたかを返します。

03 · 動作

通知はキューではなく、その場限りの合図です。

  • 通知を送ると、同じ名前を待っている現在のスクリプトがすべて再開します。
  • 待機を始める前に送られた通知は保持されません。
  • コントローラーが合図を送る前に、待機側を登録してください。
  • キーを押し続けたときに発生する反復keydownは無視されます。
  • 0、負数、有限でないタイムアウトは即時に満了します。
  • プロジェクトの開始または停止によって、未完了の待機は解除されます。

正規化と互換性の詳細は完全な動作仕様を参照してください。
